# Getting Help

## Where to Ask Questions

### Open Calls

Monthly plenary calls happen on the first Thursday of every month from 14:00 to 15:00 UTC. Attendance is open to everyone, including newcomers. No W3C account is required to view the calendar or joining information. Local times may change with daylight saving time.

The [DDS W3C Community Group calendar](https://www.w3.org/groups/cg/dds/calendar/) is the canonical source for dates, schedule changes, agendas, and public Google Meet joining links. It is separate from the group's WordPress homepage.

Subscribe once using the [public iCalendar feed](https://www.w3.org/groups/cg/dds/calendar/export/) to receive future events and updates in your own calendar:

- **Google Calendar:** On a computer, select the `+` next to **Other calendars**, then **From URL**, paste `https://www.w3.org/groups/cg/dds/calendar/export/`, and select **Add calendar**.
- **Apple Calendar:** Select **File**, then **New Calendar Subscription**, and paste the same URL.
- **Outlook on the web:** Select **Add calendar**, then **Subscribe from web**, and paste the same URL.

Subscribe by URL rather than downloading and importing a file, which creates a static copy. Calendar applications control refresh timing, so check the W3C event and mailing-list announcements for last-minute changes.

W3C sends event notifications to invited group participants, subject to their notification preferences. Joining the Community Group does not automatically subscribe your Google, Apple, or Outlook calendar; use the feed above. Future members should also subscribe rather than rely on receiving an invitation email for an existing series.

The [former Luma calendar](https://luma.com/dds-wg) is deprecated. Use the W3C calendar instead.

### Group Chat

[DDS Community Group Matrix room](https://matrix.to/#/#dds-wg:matrix.org)

Use Matrix for real-time questions, coordination, and informal discussion.

### Mailing List

Use [public-dds@w3.org](mailto:public-dds@w3.org) to send a message to the entire W3C DDS Community Group mailing list.

The mailing-list archive is public at [https://lists.w3.org/Archives/Public/public-dds/](https://lists.w3.org/Archives/Public/public-dds/). **Messages are permanently public, so avoid spam, off-topic messages, and anything private or sensitive.**

### GitHub Issues

At this stage, issues are open for any kind of discussion: bugs, features, ideas, questions. Use them freely.

See [CONTRIBUTING.md](CONTRIBUTING.md) for how to file good issues and submit PRs.
