# Getting Help

## Where to Ask Questions

### Open Calls

Monthly community calls happen on the first Thursday of every month at 14:00 UTC. Use the [DDS W3C Community Group calendar](https://luma.com/dds-wg) to participate.

### Group Chat

[DDS Community Group Matrix room](https://matrix.to/#/#dds-wg:matrix.org)

Real-time chat for quick questions and coordination. We keep it low-volume and high-signal.

### Mailing List

Use [public-dds@w3.org](mailto:public-dds@w3.org) to send a message to the entire W3C DDS Community Group mailing list.

The mailing-list archive is public at [https://lists.w3.org/Archives/Public/public-dds/](https://lists.w3.org/Archives/Public/public-dds/). **Messages are permanently public, so avoid spam, off-topic messages, and anything private or sensitive.**

### GitHub Issues

At this stage, issues are open for any kind of discussion: bugs, features, ideas, questions. Use them freely.

See [CONTRIBUTING.md](CONTRIBUTING.md) for how to file good issues and submit PRs.
